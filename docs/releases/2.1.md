Download **CopilotKey21.exe**, keep it in a permanent folder, and run it. This is the only file needed: no installer, extraction, companion DLLs, or additional runtime downloads.

- Choose Codex or Claude and click Save.
- Open More for startup settings, Chinese or English, and the project link.
- Rounded controls, system light and dark themes, and Mica where supported.
- The same EXE provides the settings window and background mapping. Icons and both languages are embedded.

Settings are created automatically in the user profile. The target app must already be installed, and the keyboard must send Win + Shift + F23. Keep the EXE in the same location after enabling startup; if you move it, turn startup off and on from its new location.

The rendering update reuses a native-resolution drawing buffer. On the development PC, main-window working memory was about 15.4 MB and private memory 2.06 MB. CPU time for 30 repaints fell by about 71%. Results vary by device.

## 中文说明

下载 **CopilotKey21.exe**，放在固定目录后运行。只需这一个文件，无需安装、解压、附带 DLL 或额外下载运行库。

- 选择 Codex 或 Claude，点击“保存”。
- 在“更多”中设置自启动、中文或英文，并访问项目链接。
- 支持平滑圆角控件、系统浅色／深色配色及受支持系统上的 Mica。
- 设置窗口和后台映射共用一个 EXE，图标与两种语言全部内置。

设置自动保存到用户目录。目标应用需事先安装，键盘需发送 `Win + Shift + F23`。开启自启动后请保持 EXE 路径不变；移动后，在新位置将自启动关闭再开启。

渲染器复用原始分辨率绘图缓冲区。在开发电脑上，主窗口工作集约 15.4 MB，私有内存约 2.06 MB；连续重绘 30 次的 CPU 时间降低约 71%。实际结果因设备而异。EXE 的 SHA-256 校验值见上方英文部分。
