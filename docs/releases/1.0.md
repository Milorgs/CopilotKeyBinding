Maps the Copilot key (`Win + Shift + F23`) to Codex on Windows x64.

Download **CopilotKey-windows-x64.zip**, extract it, and run **CopilotKey.exe**. Codex must already be installed. To start the mapper at sign-in, add a shortcut to `shell:startup`.

- Native Win32 C implementation; no .NET or AutoHotkey required.
- Runs in the background and launches Codex on key release.
- Single instance, no polling, and no logging of ordinary keys or typed text.
- Working set measured at about 5.5 MB on one Windows PC, compared with about 35 MB for the earlier .NET version.

The target app ID is `OpenAI.Codex_2p2nqsd0c76g0!App`. Keyboards that send a different Copilot key sequence are not supported by this release.

**SHA256SUMS.txt** contains the checksum for the standalone executable.

[Full version documentation](https://github.com/Milorgs/CopilotKeyBinding/blob/main/docs/versions/1.0.md)

## 中文说明

将 Windows x64 电脑的 Copilot 键（`Win + Shift + F23`）映射为打开 Codex。

下载 **CopilotKey-windows-x64.zip** 后解压运行 **CopilotKey.exe**，也可以直接下载单独的 EXE。需事先安装 Codex。需要登录后自动运行时，将快捷方式放入 `shell:startup`。

- 原生 Win32 C 实现，无需 .NET 或 AutoHotkey。
- 后台运行，松开按键时打开 Codex。
- 单实例，无轮询，不记录普通按键或输入文字。
- 在一台 Windows 电脑上测得工作集约 5.5 MB，早期 .NET 版本约为 35 MB，实际占用因设备而异。

应用标识为 `OpenAI.Codex_2p2nqsd0c76g0!App`。发送其他按键组合的键盘不在此版本支持范围内。**SHA256SUMS.txt** 提供 EXE 的校验值。
