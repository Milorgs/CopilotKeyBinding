Appearance controls and a manual update check are now available under **More**.

- Choose **System**, **Light**, or **Dark**. The choice applies immediately and is remembered after restart. System follows Windows theme changes.
- Click **Check updates** to query the latest formal GitHub release. If a newer version is available, open its download page from the prompt. The window stays responsive during the check.
- Back and link arrows use smooth strokes with rounded ends.

Download **CopilotKey22.exe**, keep it in a permanent folder, and run it. This is the only file needed; icons, both languages, settings controls, and background mapping are included. Existing 2.x settings and app selection are retained.

Codex or Claude must already be installed. The keyboard must send Win + Shift + F23. There is no automatic update download or installation.

## 中文说明

“更多”中新增外观选项和手动检查更新。

- 选择 **跟随系统、浅色或深色**，立即生效并在重启后保留；跟随系统会响应 Windows 主题变化。
- 点击 **检查更新** 查询 GitHub 最新正式版。有新版时可打开下载页，检查期间窗口仍可操作。
- 返回和链接箭头采用平滑圆头线条。

下载 **CopilotKey22.exe**，放在固定目录后运行。只需一个文件，内置图标、中英文、设置控件和后台映射。已有 2.x 设置和应用选择继续保留。

Codex 或 Claude 需事先安装，键盘需发送 `Win + Shift + F23`。升级前请先退出旧版映射程序。不会自动下载或安装更新。EXE 的 SHA-256 校验值见上方英文部分。
